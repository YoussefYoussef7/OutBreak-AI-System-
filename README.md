# OutBreak-AI-System-
An ai system that simulates the real out break of a disease and how to contain it , the system is build with reinforcement learning and a dqn agent , it's based on a real life map (city of monaco) , the system 
let's the disease spread to the whole city (worst case scenario) , then the agent starts acting and trying to save as many as possible. 
the system has a futuristic looking dashboard designed with html , css and js with animations for populations , shelters , ambulances and the agent.
techniques used : GYMNASIUM , STABLE-BASELINES3 , GIS MAPPING (MONACO) , HTML , CSS , JS
